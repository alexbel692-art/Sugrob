# Сугроб — снег на рабочем столе Windows

Снег идёт поверх всех окон, копится на верхних краях окон и на панели задач,
осыпается, когда окно двигаешь. По панели задач ездит снегоуборщик, а из сугробов
можно лепить снеговиков. Клики проходят сквозь снег, работать он не мешает.

## Скачать

**Windows:** **[Sugrob.exe](../../releases/latest/download/Sugrob.exe)** — просто запусти, программа свернётся в трей.

**Mac** (macOS 13+, Apple Silicon и Intel): **[Sugrob-mac.zip](../../releases/latest/download/Sugrob-mac.zip)** — распакуй, перетащи «Сугроб» в «Программы». Приложение не подписано Apple, поэтому первый запуск: правый клик → «Открыть» → «Открыть» (или Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»). Снежинка появится в строке меню. Для снега на Dock и лепки снеговиков разреши «Универсальный доступ». ⌃⌥S — режим лепки. Исходники — в папке `mac/`, сборка: `mac/build.sh`.

Если Windows SmartScreen предупредит: «Подробнее» → «Выполнить в любом случае» (exe не подписан).

## Сборка самостоятельно

1. Установи **.NET 8 SDK** (x64): https://dotnet.microsoft.com/download/dotnet/8.0
2. Запусти `build.bat`.
3. Готовый файл появится в `publish\Sugrob.exe`. Это один exe, .NET на других ПК не нужен.

Для разработки достаточно `dotnet run` в папке проекта.

## Что умеет

| Что | Как |
|---|---|
| Снегопад с глубиной, ветром и покачиванием | само |
| Сугробы на окнах (только на видимых частях кромки) | само |
| Сугроб на панели задач (все мониторы) | само |
| Окно сдвинули или развернули — снег осыпается и падает ниже | само |
| Снег сползает со склонов и падает с краёв окон | само |
| Снегоуборщик чистит панель задач и сбрасывает снег за край | сам раз в N минут или «Вызвать снегоуборщик» в трее |
| Снеговик | **Ctrl+Alt+S**, затем клики по сугробу: 1-й ком, 2-й, 3-й — и появляются лицо, шарф, шляпа и руки. Клик по готовому снеговику — он качается. Правый клик — разрушить. **Esc** — выход из режима |
| Стряхнуть весь снег, пауза, настройки, выход | меню значка в трее |
| Скрывается в полноэкранных играх и видео | настройка |
| Автозапуск с Windows | настройка |

Настройки: интенсивность, ветер, размер снежинок, высота сугробов, скорость накопления,
интервал снегоуборщика, 30/60 FPS.

Файлы: `%AppData%\Sugrob\settings.json`, журнал ошибок — `%AppData%\Sugrob\error.log`.

## Как устроено

- `OverlayWindow` — прозрачное окно на каждый монитор, всегда сверху,
  `WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`: мышь и фокус его не замечают.
- `World.Scan()` — 7 раз в секунду `EnumWindows` + `DWMWA_EXTENDED_FRAME_BOUNDS`: где кромки окон
  и панели задач, какие участки кромки перекрыты окнами выше по z-порядку, какое окно сдвинулось.
- Сугроб — массив высот по столбцам в 3 px с осыпанием по углу естественного откоса.
- Режим лепки ставит низкоуровневый хук мыши (`WH_MOUSE_LL`) и перехватывает только клики по снегу.
  Остальные клики уходят в окна как обычно.
- Всё считается в физических пикселях (Per-Monitor V2 DPI), поэтому корректно на 4K и с разным
  масштабом на разных мониторах.

## Если что-то не так

- **Грузит процессор.** Поставь 30 FPS и уменьши интенсивность. Прозрачное окно WPF перерисовывается
  программно, на 4K это заметнее.
- **Ctrl+Alt+S не работает.** Сочетание занято другой программой. Включай режим лепки из меню в трее.
- **Не лепится снеговик на окне программы, запущенной от администратора.** Снег на такие окна
  ложится, но хук мыши не получает кликов над ними. Это ограничение Windows.
